# 3 分钟网页 + MCP 演示脚本

这是复现流程的操作清单，尚未表示本轮真实数据库验收已完成。演示前先按 [复现步骤](reproduction.md) 启动 seekdb、API 和 Vite；确认 `/readyz` 为 `ok`。网页设为 `VITE_ARCHIVE_DATA_SOURCE=api`。不用浏览器扩展，也不用模型 API Key。

| 时间 | 操作 | 应看到的证据 |
| --- | --- | --- |
| 0:00–0:30 | 在终端导入两段仓库虚构对话；打开网页“对话档案” | 2 个平台、12 条消息，角色和顺序与 JSON 一致；此时未自动产生记忆 |
| 0:30–1:20 | 选中一条消息 → 预览候选 → 关闭；再预览、编辑并确认 | 关闭预览后记忆数不变；确认后记忆库出现新记忆，出处按钮回到原消息 |
| 1:20–2:00 | 在记忆检索页用关键词提问，筛选平台或类别，再取消勾选一条 | 结果显示真实来源和轨迹 ID；最终上下文只包含被选 ID，预算不足会标明跳过 |
| 2:00–2:30 | 使用 Agent 宿主连接 `http://127.0.0.1:8000/mcp`，调用 `memory_search`（`mode=keyword`，相同 scope） | Agent 拿到与网页同一份已确认记忆和出处；不能读取未提供的聊天历史 |
| 2:30–3:00 | 打开“召回记录”和“版本与冲突”，展示实际轨迹与旧/新版本 | 轨迹来自数据库；被替代的旧记忆可查但不参与默认检索 |

演示截图在真实 API 与 seekdb 联调后截取，不把 mock 页面当作真实结果。若时间有限，优先保留前四步并展示 [结果记录](RESULTS.md) 中带命令的实测数字。
